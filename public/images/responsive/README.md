# Responsive painted artwork

Generated by `npm run images:build` using `scripts/build-images.mjs`.

Original WebP artwork remains unchanged. Smaller WebP files use quality 90,
alpha quality 100, and high-effort encoding. AVIF uses quality 85 and 4:4:4 color
sampling to retain fine painted edges; a format set is included only when every
candidate is smaller than its WebP equivalent. The full original resolution is
available in each format set. Browsers choose a resolution from the component's
`sizes` and their screen density, avoiding unnecessary downloads without
upscaling beyond the existing source.

Filenames contain content hashes; the original fallback URL has a content hash
query parameter. `manifest.json` supplies Blade's picture component and
`report.json` records sizes for review. Rebuild and inspect images on light and
dark backgrounds when changing encoders or quality settings.

Earlier fingerprinted files are retained so cached pages and lazy-loaded images
keep resolving after an update.
