# Self-hosted fonts

These are the unchanged Latin WOFF2 subsets originally loaded from Bunny Fonts:

- `https://fonts.bunny.net/inter/files/inter-latin-{400,500,600,700,800,900}-normal.woff2`
- `https://fonts.bunny.net/jetbrains-mono/files/jetbrains-mono-latin-{400,500}-normal.woff2`

Both families use the SIL Open Font License 1.1. The accompanying OFL files come
from the Inter and JetBrains Mono directories in the Google Fonts repository.
Keep the licenses with redistributed files. `resources/css/fonts.css` retains
the original family, weight, and Unicode ranges. The build adds content hashes
to font URLs for cache invalidation.
